# 🍌 Google Flow Studio & Live Bridge

**Google Flow Studio** — это современная локальная веб-студия и высокоскоростной мост синхронизации для работы с нейросетевыми моделями генерации и редактирования изображений **Google Flow** (`flow.google.com`).

---

## ✨ Основные возможности

### 1. 🍌 Базовая генерация (Text-to-Image)
* Генерация изображений в высоком разрешении (до 4K).
* Поддержка флагманских моделей:
  * **Nano Banana 2** (NARWHAL) — быстрая генерация.
  * **Nano Banana Pro** (GEM_PIX_2) — максимальная детализация и фотореализм.
  * **Nano Banana 2 Lite** (HARBOR_SEAL) — облегченный драфт-режим.
* Полный выбор пропорций: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`.
* История генераций с быстрым скачиванием в PNG и удалением.
* Переход в редактор в один клик.

### 2. ✨ Умное редактирование (Object Replacement & Inpainting)
* **Smart Select**: Встроенный MediaPipe Object Detector автоматически определяет объекты на снимке (люди, машины, животные и т.д.).
* **Ручное выделение**: Возможность очертить любую область кадра прямоугольной рамкой.
* **Image-to-Image генерация**: Передача референсного кадра через мост в Google Flow для сохранения освещения, геометрии и фоновой композиции.
* **Side-by-Side Comparison**: Наглядное сравнение «Исходный кадр ➔ Отредактированный результат» с возможностью применить изменения и продолжить цепочку правок.

### 3. ⚡ Live Bridge & CDP Integration
* **Chrome DevTools Protocol (CDP)**: Прямое подключение к активной вкладке браузера без повторных запросов разрешений.
* **Двусторонняя синхронизация кода**: Мгновенный перенос изменений между локальной папкой `src/` и онлайн-редактором кастомных инструментов Google Flow.
* **Browser Extension & UserScript**: Поддержка подключения через Chrome-расширение или Tampermonkey.

### 4. 💻 Консольный запуск (CLI)
* Скрипт `tools/generate_flow_image.py` для вызова генерации напрямую из терминала или скриптов автоматизации.

## 🚀 Быстрый старт

### Требования
* **Node.js** 18+
* **Python** 3.10+
* Браузер (Chrome / Opera GX / Edge) с открытой вкладкой [flow.google.com](https://flow.google.com)

### 1. Установка зависимостей
```bash
npm install
pip install -r requirements.txt
```

### 2. Запуск проекта
Для одновременного запуска моста и интерфейса:
```bash
# Запуск через готовый скрипт
start_all.bat

# Или вручную в двух терминалах:
# Терминал 1 (Bridge Server):
python bridge/server.py

# Терминал 2 (Vite Frontend):
npm run dev
```

Интерфейс студии откроется по адресу: `http://localhost:5173`.

## 🔌 Подключение к Google Flow

Выберите удобный способ подключения браузера к мосту:

### Вариант 1: Через Chrome Расширение
1. Перейдите по адресу `chrome://extensions` (или `opera://extensions`).
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку `extension/`.

### Вариант 2: Через Tampermonkey / Violentmonkey
1. Установите Tampermonkey.
2. Добавьте юзерскрипт из файла [tampermonkey/flow_sync.user.js](tampermonkey/flow_sync.user.js).

## 📁 Структура проекта

```
Flow/
├── bridge/                # Backend моста (FastAPI, CDP Engine, WebSockets)
│   ├── cdp_engine.py      # Движок управления через Chrome DevTools Protocol
│   └── server.py          # Сервер API и раздачи файлов
├── src/                   # React Frontend (Google Flow Studio)
│   ├── components/        # UI-компоненты (генератор, редактор, галерея, справочник)
│   ├── hooks/             # Хуки (useObjectDetector с MediaPipe)
│   ├── services/          # Сервисы обработки и композитинга
│   └── mock-flow-sdk.ts   # Flow SDK клиент для локальной разработки
├── extension/             # Готовое Chrome-расширение для Flow
├── tampermonkey/          # Юзерскрипт синхронизации
├── tools/                 # CLI-утилиты для генерации
├── start_all.bat          # Батник запуска всей студии
├── start_bridge.bat       # Батник запуска моста
└── start_app.bat          # Батник запуска веб-интерфейса
```
